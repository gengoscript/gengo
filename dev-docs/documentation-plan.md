# Documentation work plan

## P0 — trust and correctness

- Still required: deployment commit injection, executable examples, ABI layout
  snapshots, and a tracked implementation decision for decimal scale.

## P1 — completeness

- Split guide, normative language reference, and contributor execution model.
- Add grammar, precedence, zero-value, collections, generic, and variant
  semantics backed by focused specification tests.

- Expand hardening recipes and an error catalogue.

## P2 — usability

- Heading anchors, page contents, persistent navigation, search, responsive
  tables, print styles, and progressive copy controls.
- Add operations, performance, migration, and additional runnable examples.
